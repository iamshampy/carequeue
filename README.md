# CareQueue

A mobile-first clinic onboarding demo built with Next.js. It includes the welcome page, sign-up/sign-in forms, doctor profile setup, weekly availability, and a clinic booking page with a generated QR code.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. Form and clinic details are saved only in this browser's local storage; authentication and patient bookings are demo-only. QR images are generated in the browser and are downloadable as PNGs.
